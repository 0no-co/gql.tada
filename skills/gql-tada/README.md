# gql.tada Agent Skill

This directory contains an [Agent Skills](https://agentskills.io/) compatible skill for agents that
configure, migrate, debug, optimize, or analyze gql.tada projects.

## Install

Use the GitHub directory below as the source in any standards-compatible Agent Skills installer, or
copy this directory into the skill location supported by your agent:

```text
https://github.com/0no-co/gql.tada/tree/main/skills/gql-tada
```

Installation paths and commands differ by agent. Consult your agent's skill documentation rather
than assuming this skill is published in a particular registry.

The skill uses progressive disclosure: `SKILL.md` contains the workflow and loads
`references/documentation.md` when detailed documentation links are needed.
